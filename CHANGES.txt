MongoDB port of ScholarConnect  -  how to apply
1. Copy everything in this zip over your project (same paths). Say yes to overwrite.
2. Delete server/lib/sqlfile.js (no longer used).
3. cd server ; npm install     (needs Node 20.19+; this refreshes package-lock.json)
4. cp .env.example .env  ->  set MONGODB_URI (default mongodb://127.0.0.1:27017/scholarconnect) and SESSION_SECRET
5. npm run db:init       (indexes + 55 scholarships)
6. npm run create-admin
7. npm test              (17 checks)   then   npm start
Old MySQL accounts are not copied across; the Mongo database starts empty.
